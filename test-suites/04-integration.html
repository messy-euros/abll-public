Zeffy → Ledger Pipeline — integration

A raw payment.completed flows all the way to a betting balance: map(payment) → ledger.topup({contactId,email}, cents, ref) → balance. The mapper and ledger are already green on their own; this suite tests the seam between them.

Run the suite against:

The seam under test

ingest(payment, ledger):
    const { topups, flags } = map(payment)          // component 1 (already green)
    for (t of topups)
        ledger.topup({contactId:t.contactId, email:t.email, label:t.label},
                     t.cents, t.source, t.ref)      // component 2 (already green)
    return { flags }                                // surfaced to the exception desk

What only shows up here: the ref must survive map()->topup() or a redelivered
webhook double-credits — even though both components are individually correct.
